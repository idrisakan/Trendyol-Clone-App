# 🛍️ Trendyol App Clone
Bu proje, popüler e-ticaret uygulaması Trendyol'un temel işlevlerini taklit eden bir React Native mobil uygulama klonudur. Modern kullanıcı arayüzü, sepet sistemi, ürün listeleme ve sayfalar arası geçiş gibi temel özellikleri barındırır.

✨ Özellikler
🧭 Sekmeli gezinme yapısı (Bottom Tabs)

🛒 Redux ile global sepet yönetimi

📦 Kategori ve ürün listeleme

🔍 Ürün detayı sayfası

🚀 Splash ekran (Bootsplash)

📱 Mobil uyumlu, responsive tasarım

🔁 Axios ile sahte API'den veri çekme (mock veya gerçek endpoint uyumlu)

🛠️ Kullanılan Teknolojiler
- Teknoloji	Açıklama
- React Native	Mobil uygulama geliştirme
- React	UI bileşenleri
- @react-navigation/*	Sayfalar arası geçiş (stack & tab)
- Redux / @reduxjs/toolkit	Global state yönetimi
- react-redux	Redux bağlantısı
- Axios	HTTP istekleri
- react-native-svg	SVG desteği
- react-native-safe-area-context	iOS/Android safe area yönetimi
- react-native-bootsplash	Özelleştirilmiş açılış ekranı
- iconsax-react-native	Modern ikon seti
